# sala de aula
 

Este projeto é um recurso educaional para que os alunos aprendam sobre programacão de sistemas através da elaboração de um "software".

O projeto é um sistema de gestão de sala de aula, em que será possivel:

1. adicionar alunos;
2. Remover alunos;
3. Atribuir nota a alunos;
4. conferir situação do alunos,
5. imprimir relatório de alunos,com notas;
